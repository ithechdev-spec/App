# تطبيق ALHA للأندرويد (Native Flutter) — بوت العرض والطلب الصافي

هذا المشروع هو التحويل الكامل والحرفي لبوت `Alha.py` (بناء 2.0 — العرض والطلب الصافي على بايننس سبوت) إلى تطبيق أندرويد أصلي (**Native Flutter**) يعمل بالكامل من داخل الهاتف دون الحاجة إلى خادم بايثون خارجي.

---

## ما الذي يتضمنه التطبيق؟
1. **محرك العرض والطلب الصافي (`SdEngine`) مطابق 100% للبوت الأصلي**:
   - تحديد القمم والقيعان الهيكلية المؤكدة (3 شموع على كل طرف `K = 3`).
   - رصد كسر البنية الصاعد والهابط (`BOS`) ونافذة البحث عن شمعة الرجوع (`60 شمعة`).
   - **فلتر حجم الكسر (`BOS Volume`)**: التحقق من أن حجم شمعة الكسر الصاعد أكبر من `المضاعف × متوسط حجم آخر 20 شمعة` (افتراضياً `1.5×` مع إمكانية التعديل أو الإيقاف).
   - **الدخول من منتصف المنطقة (`ج4 — Mid-Zone Limit`)**: أمر ليمت عند منتصف منطقة الطلب مع حارس سلامة شمعة الدخول (`sl_guard`) وفلتر العائد للمخاطرة الصارم `RR > 2.5`.
   - **التأمين التلقائي (`Auto-Breakeven`)**: رفع الوقف تلقائياً إلى نقطة التعادل شاملة العمولة (`+0.25%`) عند وصول السعر إلى النسبة المحددة من الهدف (افتراضياً `50%`).
2. **اتصال مباشر بـ Binance Spot API (عام + حقيقي موقع بـ HMAC-SHA256)**:
   - دلو وزن مشترك (`Rate Limiter`) يحترم حدود بايننس ويدير عقوبات `429/418` ومزامنة فرق التوقيت `-1021`.
   - التداول الورقي التجريبي (`Paper`) أو الحقيقي المباشر (`Binance Spot`) أو بيئة التجربة (`Testnet`) مع دعم تحويل رموز `1000X` وفلاتر `LOT_SIZE` و`NOTIONAL`.
3. **خدمة إشعارات تيليجرام مدمجة (`TelegramService`)**:
   - طابور إرسال ذكي مع إعادة المحاولة وفلترة الإشعارات حسب الفئة (`فتح صفقة`, `إغلاق صفقة`, `تأمين الصفقات`, `ملخص المسح`, `النظام`).
4. **تصميم واجهات Quantum UI الأصلي بـ Flutter (`RTL` عربي بالكامل + 4 ثيمات)**:
   - **الثيمات الأربعة**: النيون السماوي (`Quantum Cyan`)، الذهبي الدافئ (`Solar Gold`)، القرمزي الداكن (`Crimson Matrix`)، والنهاري الفاتح (`Crystal Day`).
   - **تبويب العمليات**: ثلاثية الملخص العلوي مع شرارة الرصيد (`Sparkline`)، عداد نسبة الفوز، مصفوفة الخانات النشطة، بطاقتا رادار الفريمات (`4H` و`1D`) مع العد التنازلي التلقائي، بطاقات الصفقات المفتوحة، رادار المناطق القريبة، وطرق عرض المناطق الثلاث (`بطاقات`، `سونار`، `جدول`) مع التثبيت بالمفضلة `⭐` والدخول اليدوي الفوري `⚡`.
   - **تبويب الأداء والأرشيف**: بطاقات التحليل التفصيلي، منحنى الرصيد التراكمي التفاعلي، خريطة الأداء الحرارية (`Performance Heatmap` للعملات وأيام الأسبوع)، وجدول الأرشيف مع التصدير إلى `CSV`.
   - **تبويب الحاسبة الشاملة (`Backtest Simulator`)**: محاكاة تاريخية شاملة على شموع بايننس سبوت مع شريط تقدم حي ومنحنى نمو المحفظة وتفصيل السنوات والأشهر.
   - **استوديو الشارت التفاعلي (`CustomPainter`)**: شموع تفاعلية مع التحريك والتكبير، أعمدة الفوليوم وشارات `BOS`، مستطيل منطقة الطلب، **وسحب خطوط الهدف `TP` والستوب `SL` مباشرة باللمس لتعديل الصفقة**، بالإضافة إلى **أداة المسطرة (`Ruler`)** لقياس النسب المئوية وعدد الشموع.

## طريقة استخراج ملف `APK` الجاهز للتثبيت

### الطريقة الأولى: سحابياً عبر GitHub Actions (بدون تثبيت أي برامج — من الجوال أو الكمبيوتر)
المشروع مزود بملف بناء تلقائي جاهز في `.github/workflows/build_apk.yml`:
1. أنشئ مستودعاً جديداً (Repository) على حسابك في **GitHub**.
2. ارفع محتويات هذا المشروع إلى المستودع.
3. ادخل إلى تبويب **Actions** في المستودع، وستجد عملية البناء **Build ALHA Android APK** تعمل تلقائياً.
4. خلال دقيقتين إلى 3 دقائق ستكتمل العملية وتظهر لك حزمة **`ALHA-SupplyDemand-Bot-APK`** جاهزة للتحميل والتثبيت مباشرة على هاتفك.

### الطريقة الثانية: محلياً عبر Flutter CLI (على الكمبيوتر)
إذا كان لديك Flutter مثبتاً على جهازك:
```bash
flutter create --platforms=android --org com.alha .
flutter pub get
flutter build apk --release
```
ستجد ملف الـ APK الجاهز في المسار:
`build/app/outputs/flutter-apk/app-release.apk`
